# Helmet-detection-python

โปรแกรมนี้ทำงานโดย ตรวจจับวัตถุในภาพด้วย AI แล้วนำบริเวณที่ตรวจพบมาหาวงกลมและพื้นที่สีขาว เพื่อทดลองวิเคราะห์หมวกกันน็อก โดยแต่ละส่วนมีหน้าที่ดังนี้ครับ
1. เตรียมเครื่องมือประมวลผลภาพ
ใช้ OpenCV สำหรับอ่านภาพ ตรวจจับวัตถุ วาดกรอบ และแสดงภาพ ส่วน NumPy ใช้จัดการข้อมูลตัวเลข เช่น พิกัดกรอบและค่าสี
2. กำหนดเกณฑ์รับผลตรวจจับ
กำหนดให้รับเฉพาะผลที่มีคะแนนคลาสมากกว่า 0.5 หรือ 50% ผลที่ต่ำกว่านี้จะถูกตัดทิ้ง ส่วนค่าขีดแบ่งคะแนนและการซ้อนทับอีกสองตัวถูกกำหนดไว้ แต่ยังไม่ได้ใช้
3. โหลดโมเดล AI
โหลดโมเดล YOLOv3 จากไฟล์โครงสร้างและไฟล์น้ำหนักที่ผ่านการฝึกมาแล้ว พร้อมอ่านรายชื่อคลาส และสุ่มสีสำหรับวาดกรอบแต่ละคลาส
4. อ่านภาพต้นฉบับ
เปิดภาพชื่อ helmet1.png แล้วอ่านความกว้างและความสูง เพื่อนำไปใช้คำนวณตำแหน่งวัตถุภายหลัง
ตัวแปรที่ตั้งไว้เก็บภาพอีกตัวหนึ่งยังอ้างถึงภาพเดียวกับต้นฉบับ จึงไม่ได้เป็นภาพสำเนาแยกต่างหาก
5. เตรียมภาพให้ AI วิเคราะห์
ปรับภาพเป็นขนาด 416 × 416 พิกเซล ปรับค่าสีให้อยู่ระหว่าง 0–1 และจัดรูปแบบข้อมูลให้ตรงกับที่โมเดลต้องการ
6. ตรวจจับวัตถุในภาพ
ส่งภาพเข้าโมเดลเพื่อให้ AI ประเมินว่ามีวัตถุอะไร อยู่ตำแหน่งไหน และมีคะแนนของแต่ละคลาสเท่าไร จากนั้นเลือกคลาสที่ได้คะแนนสูงที่สุดของแต่ละผลตรวจจับ
7. คำนวณกรอบวัตถุ
ตำแหน่งที่ AI ส่งกลับมาเป็นสัดส่วนของภาพ โปรแกรมจึงแปลงเป็นพิกเซลจริง แล้วคำนวณมุมซ้ายบน ความกว้าง และความสูงของกรอบ พร้อมเก็บคะแนนและหมายเลขคลาสไว้
8. เลือกวิเคราะห์เฉพาะคลาสหมายเลข 0
โปรแกรมทำขั้นตอนต่อไปเฉพาะวัตถุที่เป็นคลาส 0 ซึ่งหมายถึงชื่อแรกในไฟล์รายชื่อคลาส ต้องดูไฟล์นั้นจึงจะทราบว่าเป็นหมวก คน หรือวัตถุชนิดอื่น
9. วาดกรอบและชื่อวัตถุ
วาดกรอบล้อมรอบวัตถุ พร้อมเขียนชื่อคลาสเหนือกรอบ และทำพื้นหลังข้อความโปร่งแสงเพื่อให้อ่านง่าย จากนั้นตัดภาพเฉพาะบริเวณภายในกรอบออกมาวิเคราะห์
10. ลดจุดรบกวนและค้นหาวงกลม
ทำให้ภาพที่ตัดมามีจุดรบกวนน้อยลง แล้วแปลงเป็นภาพขาวดำเพื่อค้นหารูปร่างวงกลม ผลที่ได้จะเป็นตำแหน่งศูนย์กลางและรัศมีของวงกลม
ในโปรแกรมนี้ผลวงกลมถูกพิมพ์ออกมาเท่านั้น ยังไม่ได้วาดวงกลมหรือใช้ตัดสินว่าเป็นหมวก
11. หาพื้นที่สีขาวหรือสีสว่าง
เลือกพิกเซลที่ค่าสีน้ำเงิน เขียว และแดงสูงพร้อมกัน ซึ่งเป็นสีขาวหรือสีเทาสว่าง แล้วสร้างภาพแยกพื้นที่ที่ผ่านเงื่อนไขให้เป็นสีขาว ส่วนพื้นที่อื่นเป็นสีดำ
แม้ตัวแปรจะชื่อ HSV แต่ภาพในขั้นตอนนี้ยังไม่ได้แปลงเป็นระบบสี HSV และเงื่อนไขที่ใช้ตรวจหาสีขาว ไม่ใช่สีแดงตามคำอธิบายในไฟล์
12. รวมค่าพื้นที่สีขาว
นำค่าพิกเซลของภาพที่แยกสีมารวมกัน ยิ่งมีพื้นที่สีขาวมาก ค่าที่ได้ก็ยิ่งสูง แต่ค่านี้ยังไม่ได้ถูกนำไปตั้งเงื่อนไขตัดสินเรื่องหมวก
13. แสดงภาพผลลัพธ์
แสดงภาพเต็มพร้อมกรอบ ภาพที่ตัดมา ภาพขาวดำ และภาพแยกพื้นที่สีขาว จากนั้นรอให้ผู้ใช้กดปุ่มเพื่อปิดหน้าต่าง หากตรวจพบหลายวัตถุ ภาพที่ตัดมาในหน้าต่างท้ายโปรแกรมจะแสดงเฉพาะวัตถุสุดท้ายที่ถูกวิเคราะห์
สถานะของโปรแกรม: ตรวจจับวัตถุและวิเคราะห์ลักษณะภาพได้ แต่ยังไม่มีขั้นตอนสรุปว่า “ใส่หมวกกันน็อก” หรือ “ไม่ใส่หมวกกันน็อก” และหากไม่พบคลาส 0 โปรแกรมจะเกิดข้อผิดพลาดตอนแสดงภาพ เพราะยังไม่มีภาพวิเคราะห์ให้แสดงครับ
